# klipper-doctor docs

Index of this repo's documentation. Every doc in this folder is linked here, one line each.

- [AGENTS.md](../AGENTS.md): commands, conventions and traps for coding agents (CLAUDE.md imports it).
- [ARCHITECTURE.md](ARCHITECTURE.md): components, data flow, storage, auth, external services.
- [DECISIONS.md](DECISIONS.md): dated record of why it is built the way it is.
- [brand.md](brand.md): who it speaks as: name, voice, copy bank, assets, contact and legal (draft, needs review).
- [README.md](../README.md): what it is and how to use it; stands in for a PRD.
- [usage.md](usage.md): the options, several files, CI, pre-commit, silencing a finding, shell completions and the library.
- [rules.md](rules.md): every rule and the Klipper docs page or source it comes from, with a generated table.
- [examples.md](examples.md): real before and after examples of what Klipper logs and what klipper-doctor says.
- [accuracy.md](accuracy.md): how often the report names the problem, measured on forum and GitHub logs, with the method.
- [CONTRIBUTING.md](../CONTRIBUTING.md): how to report a wrong diagnosis, add a rule and cut a release.
- [CHANGELOG.md](../CHANGELOG.md): release notes.
